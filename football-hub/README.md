# گل‌باکس — سایت آمار فوتبال (سبک FotMob) + هاب ویژه رئال مادرید

سایت استاتیک (HTML/CSS/JS خالص، بدون build) که داده‌ها را از **API-Football v3 (api-sports.io)** می‌گیرد.

## اجرا
کلید API را در فایل `js/config.local.js` بگذارید (این فایل در git ذخیره نمی‌شود):
```js
window.LOCAL_API_KEY = 'کلید-شما';
```
یا بعد از باز کردن سایت، کلید را در ⚙ تنظیمات وارد کنید (در مرورگر ذخیره می‌شود).

```bash
cd football-hub
python3 -m http.server 8080
# سپس http://localhost:8080 را باز کنید
```

## امکانات
- **مسابقات**: بازی‌های هر روز (۳ روز قبل تا ۳ روز بعد) به تفکیک لیگ، حالت «زنده» با بروزرسانی خودکار
- **صفحه بازی**: رویدادها، ترکیب روی زمین با نمره بازیکنان، آمار کامل (xG، مالکیت، شوت…)، آمار فردی همه بازیکنان، بهترین بازیکن زمین، رودررو، پیش‌بینی
- **لیگ**: جدول با رنگ سهمیه‌ها و فرم، بازی‌ها به تفکیک هفته، گلزنان، پاسورها، کارت‌ها
- **تیم**: بازی بعدی با شمارش معکوس، نتایج، جایگاه جدول، آمار تیمی (گل بر اساس دقیقه، رکوردها، سیستم‌ها)، آمار بازیکنان، ترکیب
- **بازیکن**: آمار فصل در همه رقابت‌ها، تفکیک رقابت‌ها، افتخارات
- **جستجو** تیم و بازیکن
- **هاب رئال مادرید** (`#/madrid`) با تم سفید/طلایی/بنفش سلطنتی
- **پیش‌نمایش ویژه بازی بعدی رئال**: شانس پیروزی، ترکیب احتمالی، ستاره‌های فصل، شناخت حریف، تاریخچه رویارویی، غایبان

## نکته‌ها
- از ⚙ می‌توانید کلید و **فصل** را عوض کنید و سهمیه روزانه را ببینید.
- پلن رایگان api-sports روزانه ۱۰۰ درخواست دارد و ممکن است به فصل جاری دسترسی نداشته باشد؛ در این صورت فصل قدیمی‌تری انتخاب کنید.
- پاسخ‌ها در localStorage کش می‌شوند تا سهمیه سریع تمام نشود.
