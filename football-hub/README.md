# گل‌باکس — سایت آمار فوتبال (سبک FotMob) + هاب ویژه رئال مادرید

سایت استاتیک (HTML/CSS/JS خالص) که داده‌ها را از **SofaScore** می‌گیرد.
SofaScore به مرورگرِ سایت‌های دیگر مستقیم جواب نمی‌دهد، برای همین یک واسط کوچک در `api/sofa.js` درخواست‌ها را از طرف سایت می‌فرستد و نتیجه را کش می‌کند.

## اجرا
- **روی Vercel:** پوشه `football-hub` را به‌عنوان Root Directory بدهید؛ `api/sofa.js` خودکار به یک تابع serverless تبدیل می‌شود.
- **روی کامپیوتر خودتان:** `node server.js` (Node 18 به بالا) و سپس `http://localhost:8080`.

## امکانات
- **مسابقات:** بازی‌های هر روز به تفکیک لیگ، حالت «زنده» با بروزرسانی خودکار
- **صفحه بازی:** رویدادها، ترکیب روی زمین با نمره بازیکنان، آمار کامل به تفکیک نیمه، آمار فردی، بهترین بازیکن زمین، رودررو، فرم پیش از بازی و پیش‌بینی هواداران
- **لیگ:** جدول با رنگ سهمیه‌ها، بازی‌ها به تفکیک هفته، گلزنان، پاسورها، بهترین نمره‌ها
- **تیم:** بازی بعدی با شمارش معکوس، نتایج، جایگاه جدول، آمار فصل، ستاره‌ها، ترکیب
- **بازیکن:** مشخصات، آمار فصل در هر رقابت، بازی‌های اخیر
- **جستجو:** تیم، بازیکن و لیگ
- **هاب رئال مادرید** (`#/madrid`) و **پیش‌نمایش ویژه بازی بعدی رئال** با تم سفید/طلایی/بنفش

## نکته
API سوفااسکور رسمی نیست و ممکن است بدون اطلاع تغییر کند یا درخواست‌ها را مسدود کند.
