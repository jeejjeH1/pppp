# گل‌باکس — سایت آمار فوتبال (سبک FotMob) + هاب ویژه رئال مادرید

سایت استاتیک (HTML/CSS/JS خالص) که داده‌ها را از **API عمومی ESPN** می‌گیرد؛ کلید و محدودیت روزانه ندارد.
مرورگر مستقیم از ESPN می‌خواند و اگر شبکه‌ای جلوی آن را گرفت، واسط `api/espn.js` روی Vercel درخواست را می‌فرستد.

## اجرا
- **روی Vercel:** پوشه `football-hub` را به‌عنوان Root Directory بدهید؛ `api/espn.js` خودکار به یک تابع serverless تبدیل می‌شود.
- **روی کامپیوتر خودتان:** `node server.js` (Node 18 به بالا) و سپس `http://localhost:8080`.

## امکانات
- **مسابقات:** بازی‌های هر روز در ۱۷ رقابت اصلی، حالت «زنده» با بروزرسانی خودکار
- **صفحه بازی:** رویدادها، ترکیب روی زمین (گل و کارت روی بازیکن)، همه آمار تیمی بازی، همه آمار فردی بازیکنان، گزارش لحظه‌به‌لحظه، رودررو، فرم دو تیم، شانس نتیجه از روی ضرایب، ستاره‌های دو تیم، جدول و اخبار
- **لیگ:** جدول با رنگ سهمیه‌ها، بازی‌های هر هفته، برترین‌های آماری، اخبار
- **تیم:** بازی بعدی با شمارش معکوس، نتایج همه رقابت‌ها، آمار فصل (خانه/خارج/هر رقابت)، بازیکنان و آمارشان، مصدومان، اخبار
- **بازیکن:** مشخصات، آمار فصل و آمار همه فصل‌ها، اخبار
- **هاب رئال مادرید** (`#/madrid`) و **پیش‌نمایش ویژه بازی بعدی رئال** با تم سفید/طلایی/بنفش

## نکته
API ESPN رسمی و مستند نیست و ممکن است ساختارش بدون اطلاع تغییر کند.
