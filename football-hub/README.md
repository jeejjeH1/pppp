# گل‌باکس — سایت آمار فوتبال (سبک FotMob) + هاب ویژه رئال مادرید

سایت استاتیک (HTML/CSS/JS خالص) که داده‌ها را از **Sportmonks Football API v3** می‌گیرد.
مرورگر به واسط `api/sm.js` درخواست می‌دهد و واسط با کلید Sportmonks به API وصل می‌شود.

## کلید API
کلید هرگز در کد نیست. یکی از این دو راه:
- **روی Vercel:** در تنظیمات پروژه یک متغیر محیطی به نام `SPORTMONKS_API_TOKEN` بسازید و دوباره منتشر کنید. همه بازدیدکننده‌ها بدون تنظیم از آن استفاده می‌کنند.
- **در مرورگر:** از ⚙ تنظیمات کلید را وارد کنید؛ فقط در همان مرورگر ذخیره می‌شود و همراه هر درخواست به واسط فرستاده می‌شود.

## اجرا روی کامپیوتر
```bash
cd football-hub
SPORTMONKS_API_TOKEN=کلید-شما node server.js
# http://localhost:8080
```

## امکانات
- **مسابقات:** بازی‌های هر روز در لیگ‌های پلن شما، حالت «زنده» با دقیقه بازی
- **صفحه بازی:** رویدادها، ترکیب روی زمین با نمره و گل/کارت بازیکنان، همه آمار تیمی، همه آمار فردی بازیکنان، گزارش لحظه‌به‌لحظه، رودررو، فرم دو تیم، پیش‌بینی نتیجه، جدول
- **لیگ:** جدول با رنگ سهمیه‌ها، بازی‌های هر هفته، گلزنان، پاسورها، کارت‌ها
- **تیم:** بازی بعدی با شمارش معکوس، نتایج، آمار فصل (خانه/خارج/هر رقابت)، بازیکنان و آمار فصلشان، مصدومان
- **بازیکن:** مشخصات و همه آمار فصل‌ها به تفکیک رقابت
- **هاب رئال مادرید** (`#/madrid`) و **پیش‌نمایش ویژه بازی بعدی رئال** با تم سفید/طلایی/بنفش

بخش‌هایی مثل پیش‌بینی، گزارش لحظه‌به‌لحظه و نمره بازیکنان به پلن Sportmonks بستگی دارند؛ اگر در پلن نباشند، آن بخش پنهان می‌ماند.
